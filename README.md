# Rovina Massas Artesanais — Cardápio Digital

Cardápio online com pedido via **WhatsApp**, responsivo (celular e computador).
Vitrine estática: o pedido é montado no navegador e enviado pelo WhatsApp do
estabelecimento. Sem backend, sem banco de dados.

> Desenvolvido por **MAFSOFT — Maffei Software Ltda** (Londrina/PR).

## Ver no ar (GitHub Pages)

1. Repositório → **Settings → Pages**
2. Em **Source**, selecione a branch `main` e a pasta `/ (root)`
3. Salve. Em ~1 minuto o site fica disponível em:
   `https://pcmafei.github.io/rovina-cardapio/`

## ⚠️ Conteúdo público

Este repositório é **público**. Ficam visíveis a qualquer pessoa as fotos dos
produtos (embutidas no `index.html`) e o número de WhatsApp. Esses dados já são
públicos no Instagram do negócio.

## Alterações

Qualquer mudança (preços, itens, fotos) é feita editando o `index.html` e
versionada aqui no repositório pela MAFSOFT.
